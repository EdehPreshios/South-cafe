Windows & GitHub Offline Setup Guide

Option A: Direct Offline Windows Desktop Use (No Internet)

  1. Save this file directly to your desktop as index.html.
  2. Double-click the file to open it in Google Chrome or Microsoft Edge.
  3. All cart entries, order numbers, and Z-report shift totals auto-save instantly to your computer's browser storage (localStorage).

Option B: Hosting via GitHub Pages (Cloud Access)

  1. Create a free account on GitHub.com.
  2. Create a new repository named south-coffee-pos.
  3. Upload this single index.html file to the main branch.
  4. Navigate to Settings > Pages in your repository menu.
  5. Set Source to Deploy from a branch (main) and click Save.
  6. Your terminal will be live at: https://yourusername.github.io/south-coffee-pos/
Thermal Printer Setup Tip

In Chrome print settings, select your 58mm / 80mm ESC/POS thermal receipt printer, set margins to None, and check the box for Background graphics to ensure solid dark formatting.
